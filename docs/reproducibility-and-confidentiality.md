# Reproducibility and confidentiality

This portfolio is designed for faculty evaluation without disclosing unpublished or collaborator-owned materials.

## Public now

- research questions and project roles;
- data scale and analytical workflow;
- software versions and parameter decisions;
- limitations and interpretation boundaries;
- links to published work.

## Withheld until publication or approval

- raw sequencing and phenotype data;
- unpublished manuscript figures and tables;
- collaborator-owned scripts and experimental records;
- sample identifiers that could expose breeding materials;
- full pipelines containing restricted filesystem paths or data locations.

## Planned sanitized release

For at least one featured project, the intended public release after publication is:

1. a small synthetic dataset matching the input schema;
2. configuration files with all paths removed;
3. modular scripts for QC summaries, association visualization, and promoter-window statistics;
4. a frozen software environment;
5. a one-command demonstration workflow;
6. expected-output checks.

The goal is to demonstrate reproducible analytical reasoning without misrepresenting access to data or code that cannot yet be shared.
